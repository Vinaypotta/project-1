AFTER MODIFING A FILE STEPS 
->GIT ADD & GIT COMMIT


types of changes:
	untracked files - the files newly created or which git has no idea.(files not present at the time of clone).
	modified - the files in which changes are made.
	unmodified - the files which are not changed.
	staged - if the untracked/modified changed added to git add then those are staged.
