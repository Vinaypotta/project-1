Git Commands — Quick HTML Reference

Common Git commands with short explanations and examples. Use the search box to filter.

git init

Create a new local Git repository in the current directory.

git init
# then add files and commit
Creates .git/
git clone

Create a local copy of a remote repository.

git clone https://github.com/user/repo.git
# clones into ./repo
Copies history & branches
git status

Show the working tree status: staged, unstaged, untracked files.

git status --short
# shows short summary
Use before commit
git add

Stage file changes to be included in the next commit.

git add file.txt
git add .     # stage all changes
Stages to index
git commit

Record staged changes in the repository history with a message.

git commit -m "Add feature X"
git commit --amend    # modify last commit
Atomic snapshot
git push

Upload local commits to a remote repository (e.g., origin).

git push origin main
git push --set-upstream origin feature
Requires remote & permission
git pull

Fetch from remote and merge into current branch (fetch + merge).

git pull origin main
# or use git pull --rebase to rebase instead of merge
Convenience command
git fetch

Download objects and refs from remote, without merging them into your branch.

git fetch origin
git branch -r    # see remote branches
Safe update
git branch

List, create, or delete branches.

git branch            # list local
git branch feature     # create branch
git branch -d feature  # delete
Use with git checkout / switch
git checkout

Switch branches or restore working tree files (older command). Use git switch for branch changes.

git checkout main
git checkout -b feature   # create & switch
Legacy; prefer git switch
git switch

Modern command to switch branches or create and switch in one step.

git switch feature
git switch -c feature
Simpler branch switching
git merge

Merge another branch into the current branch, creating a merge commit (unless fast-forward).

git checkout main
git merge feature
May produce conflicts
git rebase

Reapply commits on top of another base tip; rewrites history (use carefully on shared branches).

git rebase main
git rebase --continue
History rewriting
git log

Show commit history with details; supports many formatting options.

git log --oneline --graph --decorate --all
git log -p file.txt
Use --oneline for compact view
git diff

Show changes between commits, branches, or working tree and index.

git diff             # unstaged changes
git diff --staged     # staged vs HEAD
git diff main..feature
Visualize changes
git reset

Reset current HEAD to a specified state. Modes: --soft, --mixed, --hard (use with care).

git reset --soft HEAD~1   # keep changes staged
git reset --hard HEAD~1     # discard
Dangerous with --hard
git rm

Remove files from the working tree and the index (stages deletion).

git rm file.txt
git rm --cached file.txt   # stop tracking, keep file
Stages deletion
git stash

Temporarily save changes that are not ready to be committed and clean the working directory.

git stash push -m "WIP"
git stash list
git stash pop
Useful for context switching
git remote

Manage set of tracked repositories (remotes).

git remote -v
git remote add origin https://...git
List & manage remotes
git tag

Create, list, or delete tags to mark specific commits (lightweight or annotated).

git tag v1.0.0
git tag -a v1.0.0 -m "Release 1.0"
Useful for releases
git revert

Create a new commit that undoes the changes introduced by an earlier commit (safe for public branches).

git revert abc1234
Non-destructive undo
git show

Display information about objects (commits, tags, blobs). Useful to inspect a commit.

git show HEAD
git show abc1234
Inspect commit content
git blame

Show which revision and author last modified each line of a file.

git blame file.txt
Line-level history
Tip: run git --help or git --help for detailed docs. This page is a compact cheat-sheet.
